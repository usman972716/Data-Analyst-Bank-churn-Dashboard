# Data-Analyst-Bank-churn-Dashboard
Bank Customer Churn Analysis using Power BI to understand customer behavior and identify churn patterns. The dashboard analyzes credit cards by gender and age group, active members by country, churn by age group, and total balance by gender using interactive visuals and DAX measures.
## SQL Analysis Questions
How many total customers are there?
How many customers have churned and how many have been retained?
What is the overall churn rate (%)?
How many customers churned by country?
What is the total number of churned customers by gender?
How many active members are there by country?
How many customers have a credit card?
